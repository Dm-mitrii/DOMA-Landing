# DOMA — лендинг для GitHub Pages

Статический сайт на HTML/CSS/JS, без сборщика и серверной части.

## Языки

- `index.html` — русская версия;
- `sr/index.html` — сербская версия на латинице;
- переключатель `RU / SR` работает на обеих версиях;
- немецкая версия и пункт `DE` удалены.

Сербская версия использует те же изображения и стили. Для сербской формы телефон не ограничивается российской маской `+7`, чтобы можно было указать международный номер.

## Публикация

1. Создайте новый GitHub-репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните. Через несколько минут сайт будет опубликован.

## Форма заявки

Русская и сербская формы отправляют данные через FormSubmit на `d2359011@gmail.com`.

При первой отправке FormSubmit пришлёт на этот адрес письмо подтверждения. Нужно один раз подтвердить адрес, после чего заявки будут приходить на почту. Документация сервиса: https://formsubmit.co/documentation

Форма собирает:
- имя;
- телефон;
- необязательный комментарий;
- обязательное согласие на обработку персональных данных.

В теме письма сербские заявки отмечаются как `DOMA (SR)`.

## Что заменить перед публичным запуском

- рабочий телефон и реальные способы связи;
- WhatsApp-ссылку;
- реквизиты оператора персональных данных в русских и сербских юридических страницах;
- при необходимости FormSubmit на собственный обработчик или другой сервис форм;
- рабочее название DOMA после юридической проверки.

## Файлы

- `index.html` — русская главная страница;
- `sr/index.html` — сербская главная страница;
- `styles.css` — общие стили и адаптив;
- `script.js` — меню, раскрытие комментария, телефонная маска для RU и AJAX-отправка формы;
- `privacy.html`, `consent.html` — русские юридические страницы;
- `sr/privacy.html`, `sr/consent.html` — сербские юридические страницы;
- `assets/` — общие изображения.
